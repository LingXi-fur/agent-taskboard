## 背景

`atb`（agent-taskboard）让多个 AI 编程 Agent 并行干活不失控：任务单 → 独立 worktree → 越界检查 → 跨任务冲突 → 按验收清单审查。核心命令已经由 OpenCode 写完（T001–T003），但仓库首页还是一句话的占位 README，没有 CI，也没有能让陌生人 5 分钟看懂的演示。目标是发到 GitHub 后让人愿意 star 和 clone。

**和 OpenCode 并行**：OpenCode 正在 `opencode/t003-board-review` 上返工 `src/**`，本任务只碰文档、CI 和示例，`src/**`、`tests/**` 都在 deny 里，不会冲突。T004 会在 T003 合并之后再合并，所以 CI 里跑 walkthrough 依赖 T003 的命令没有问题。

## 工作方式

```bash
cd /Users/a123/代码/agent-taskboard
PYTHONPATH=src python3 -m agent_taskboard start T004      # 建 worktree ../agent-taskboard-tasks/T004，写回 base/branch
PYTHONPATH=src python3 -m agent_taskboard prompt T004     # 生成完整交接文本（含 allow/deny 和规则）
cd /Users/a123/代码/agent-taskboard-tasks/T004
```

`start` 会改动主仓库的 `.taskboard/tasks/T004.md`，这个改动留在主仓库，**不要**提交到你的分支。

要了解命令，读 `DESIGN.md` 第 4 节和 `PYTHONPATH=src python3 -m agent_taskboard <命令> --help`。`status`、`conflicts`、`review`、`rework` 四个命令还在 T003 分支上，演示时用 `PYTHONPATH=/Users/a123/代码/agent-taskboard-tasks/T003/src`。
