## 背景

`docs/design/console.md` 的第三、四阶段还差两项比较独立的功能：

1. **第三阶段：** "`atb prompt` asks agents to run `atb note` at milestones"。`atb note` 已经有了（T034），但 agent 拿到的交接提示里没有提到它，所以没人用。
2. **第四阶段：** `atb serve --observe`。不需要 `.taskboard/`，只显示本机的 agent 会话，让没用 atb 管任务的人也能把控制台当作"本机 agent 活动面板"。

## 要做的事

### 1. `atb prompt` 加入备注说明

- **加在哪：** 生成的交接提示里加一小节"进度备注"，中英文都要有，跟随现有的 `--lang`。
- **写什么：** 提醒 agent 在这三个时间点各运行一次 `atb note ID "…"`：开工时、遇到阻塞时、提交评审前。阻塞时要写清卡在哪、需要谁做什么。
- **示例命令：** 给出完整的命令，ID 要替换成真实任务 ID。命令要能在任务 worktree 里直接运行（T034 已经保证备注会写到主仓库）。
- **长度：** 这一节不超过 6 行，提示的其他部分不要改动。
- **测试：** 检查生成的提示里有这一节，而且命令中的 ID 正确。

### 2. `atb serve --observe`

- **能在哪启动：** 在任何目录都能启动，不要求是 git 仓库，也不要求有 `.taskboard/`。
- **页面：** 只显示会话区，以及按 agent 分组的最近 24 小时活动泳道（数据来自会话的开始和最后活动时间）。任务表、任务详情、就绪检查都隐藏。顶部写明"观察模式：只显示本机 agent 会话"。
- **API：**
  - `/api/v1/overview` 返回 `mode: "observe"`。
  - `/api/v1/sessions` 照常工作。
  - 任务相关的接口返回 404，并附一条 JSON 错误说明。
  - 在 `docs/api.md` 里写明以上行为。
- **自动切换：** 不带 `--observe`、但当前目录不是 atb 仓库时，不要直接报错退出，而是打印提示并自动进入观察模式。
- **安全：** Host 白名单和只读等现有安全规则全部保留，测试里要覆盖观察模式下伪造 Host 的情况。
