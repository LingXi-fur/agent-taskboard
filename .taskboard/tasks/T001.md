## 要做的事

1. **`config.py`**
   - `find_repo_root(start)`：用 `git rev-parse --show-toplevel` 定位仓库根目录。注意在 worktree 里执行时，返回的是 worktree 自己的根目录。
   - 读取 `.taskboard/config.toml`：缺失的字段用默认值补齐（见 DESIGN §3）；未知字段保留，不报错；类型不对时报清楚的错误。
   - `worktree_root` 里的 `{repo}` 替换成仓库目录名，再解析成绝对路径（相对路径以仓库根目录为基准）。
2. **`sheet.py`**
   - `parse(text) -> Sheet`：头部以 `+++` 开始、以 `+++` 结束，中间用 `tomllib` 解析，剩下的部分是正文。必填字段只有 `id`、`title`、`status`。`status` 必须是 DESIGN 里列出的 6 个状态之一。列表字段缺省为空列表。`created` 可以是 TOML datetime 或字符串。
   - `dump(sheet) -> str`：往返稳定，即 `parse(dump(parse(x)))` 与 `parse(x)` 相等。头部字段按固定顺序输出；`tomllib` 只能读不能写，所以要自己写一个小的 TOML 序列化，只需要支持字符串、字符串列表、datetime 和布尔值，字符串转义要正确，包括引号、反斜杠、换行和 Unicode。
   - `next_id(tasks_dir, prefix)`：返回 `T001`、`T002`……，跳过已有编号。并发不用考虑。
   - `slugify(title)`：用于分支名，转小写，只保留 `[a-z0-9-]`，最长 40 个字符；中文标题退化为用 id 当 slug（比如 `t003`）。
   - 新任务单模板：正文包含 `## 背景`、`## 要做的事`、`## 验收` 三节，验收节放两个 `- [ ]` 占位项。
3. **`scope.py`**（纯函数）
   - `match(path, pattern)`：路径一律是以 `/` 分隔的仓库相对路径。`*` 不跨越 `/`，`**` 匹配零层或多层目录，`?` 匹配单个字符。不要直接用 `fnmatch`，因为它的 `*` 会跨越 `/`。
   - `classify(paths, allow, deny) -> {path: "ok"|"denied"|"outside"}`：deny 优先；allow 为空时，没有被 deny 的路径都算 ok。
   - 表驱动测试至少 25 条，覆盖：`**` 位于开头、中间、结尾；`tests/test_*.py` 不能匹配 `tests/sub/test_x.py`；点文件；带空格或中文的路径；deny 和 allow 同时命中。
4. **`cli.py`**：`atb init`、`atb new`、`atb list`、`atb show`
   - `init`：创建 `.taskboard/config.toml` 和 `tasks/`。已经存在时**不覆盖**，提示后以退出码 0 返回。git 版本低于 2.38 时给出警告（不是错误）。
   - `new "标题" --agent X --allow G --deny G --depends ID`：生成任务单，打印路径。`--allow`、`--deny`、`--depends` 都可以重复传。依赖的 ID 不存在时以退出码 2 报错。
   - `list [--status S] [--json]`：表格列出 ID、状态、Agent、标题。中文标题要按显示宽度对齐（东亚宽字符占 2 列，参考 `unicodedata.east_asian_width`）。
   - `show ID [--json]`：显示头部字段和正文。
   - 退出码约定见 DESIGN §4。所有子命令都支持 `--json`，输出稳定的键名。
5. **测试**：放在 `tests/` 下，用 unittest。git 相关的测试在 `tempfile.TemporaryDirectory()` 里 `git init` 出真实仓库，并设置 `GIT_CONFIG_NOSYSTEM=1`、`HOME=<临时目录>`，避免读到用户的全局 git 配置。
   - 必须有一个测试直接解析仓库里的 `.taskboard/tasks/T001.md`（也就是这份任务单），断言 id、allow、deny 都正确，并且往返稳定。
