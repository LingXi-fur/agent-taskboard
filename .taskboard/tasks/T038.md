## 背景

设计文档第四阶段的第一项是预算：`docs/design/console.md` 的 "Cost and budgets" 一节。T036 已经能按任务和会话统计 token，但还没有"这个 agent 今天/本周用了多少、离上限还有多远"的视图。我们同时用好几个有额度的 agent 窗口，这正是最需要看到的东西。

**只做 token 预算，不做金额。** atb 不内置价格表；金额预算以后再说。

## 要做的事

1. **配置**：在 `.taskboard/config.toml` 里可选地写：

   ```toml
   [budgets.opencode]
   tokens_per_day = 50000000
   tokens_per_week = 200000000
   ```

   - 两个键都可选。
   - 写了不认识的键，或者值不是正整数，`atb doctor` 要报告出来。
   - 没写任何预算时，所有地方照旧，不显示预算。
2. **统计口径**：
   - 按 agent 汇总本机会话的 token：用 T036 的 `usage`，按会话最后活动时间落在哪一天归属。
   - "今天"和"本周"按本地时区算，一周从周一开始。
   - 某个 agent 的会话里没有用量数据时，显示"无数据"，不要显示 0。
3. **显示**：
   - `atb stats` 新增"预算"一节：每个 agent 的已用量、上限、百分比。超过 80% 标"接近上限"，超过 100% 标"已超出"。状态要用文字和图标一起表示，不能只靠颜色。
   - 控制台新增预算面板，放在任务表下面。没有配置预算时不显示这个面板。
   - `/api/v1/overview` 返回 `budgets` 字段，并在 `docs/api.md` 里写明。
4. **文档**：README 两份各加一小段配置示例。
