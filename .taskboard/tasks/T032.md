## 背景

atb 要开源给大家用（见 `docs/design/console.md`）。仓库里已经有英文的 `CONTRIBUTING.md`，但没有中文版，也没有 issue 和 PR 模板。

## 要做的事

1. **`CONTRIBUTING.zh-CN.md`：** 忠实翻译 `CONTRIBUTING.md`，命令和路径保持原样。两份文件开头互相链接。
2. **Issue 模板**（`.github/ISSUE_TEMPLATE/`，用 GitHub 的 YAML issue forms）：
   - `bug_report.yml`：atb 版本（`atb --version`）、操作系统、Python 版本、复现步骤、期望结果、实际结果、`atb doctor` 的输出。
   - `feature_request.yml`：要解决什么问题、建议的做法、考虑过的替代方案。
   - `adapter_request.yml`：想要支持的 agent 工具、它的会话记录在本机的位置和格式（提醒用户先脱敏，不要贴提示词和密钥）、版本号。
   - `config.yml`：`blank_issues_enabled: false`。
   - 模板的标题和说明用英文，每个字段的说明后面加一句中文。
3. **PR 模板** `.github/pull_request_template.md`：改了什么、为什么改、怎么测试的（`PYTHONPATH=src python3 -m unittest discover -s tests`）、是否更新了文档和 CHANGELOG。

## 规则

- 只新建上面这些文件，不改 `CONTRIBUTING.md` 正文（只允许在开头加一行指向中文版的链接）。
- 不要改 `.github/workflows/`。
- YAML 必须合法：用 `python3 -c "import yaml"` 能用就用它校验；不能用就仔细检查缩进，并在回报里说明是怎么检查的。不要为了校验安装任何依赖。

## 验收

- [ ] 回报列出新建的文件
- [ ] `PYTHONPATH=src python3 -m unittest discover -s tests` 通过
