**本任务只做准备：不打 tag、不 push、不发布到 PyPI。** 这三件事由用户决定，主会话执行。

## 要做的事

1. 版本号改为 `0.2.0`：`pyproject.toml` 和 `src/agent_taskboard/__init__.py`。如果有测试检查两处版本一致，确认它通过。
2. CHANGELOG：把 `[Unreleased]` 改为 `## [0.2.0] - <日期>`，日期先写 `YYYY-MM-DD`，由主会话发版时填。上面留一个空的 `## [Unreleased]`。逐条核对每一项都有中英双语、没有重复，并把同类项合并整理。底部的比较链接也要补上。
3. `docs/release.md` / `docs/release.zh-CN.md`：核对手动发布步骤和当前元数据一致（PEP 639、`setuptools>=77.0`、`twine check --strict`）；写明"先打 tag 再上传"的顺序，以及发布前要跑的检查清单。

5. 本地执行 `python -m build` 和 `python -m twine check --strict dist/*`，把输出汇总写进回报。`dist/` 不要提交。pip 镜像有问题时，加 `PIP_INDEX_URL=https://pypi.org/simple`。

## 追加（主会话 2026-11-19）：T025 的文档

T025（`atb new --body`、`atb edit`、`--copy-to`）已合并。0.2.0 要包含它，请在 `docs/guide.md`、`docs/guide.zh-CN.md` 和两份 README 的命令表里补上"写入与修改任务正文"一节，中英文内容一致：

- `atb new TITLE ... --body @FILE`，或者 `--body -` 从 stdin 读取
- `atb edit ID`：`--body`、`--title`、`--agent`、`--add-allow`/`--remove-allow`/`--add-deny`/`--remove-deny`（可重复）；不会改 id/status/branch/base；done 和 dropped 任务拒绝编辑
- `--copy-to DIR`：额外写一份 `DIR/ATB_TASK_<ID>.md`，目录必须已存在
- 写入时规范化正文（头部后一个空行、结尾一个换行），解析不回来的任务单不写

每个参数都要先用 `atb new --help` 和 `atb edit --help` 核对过再写进文档。CHANGELOG 里 T025 的条目已经由主会话写好，整理 0.2.0 时保留它。
