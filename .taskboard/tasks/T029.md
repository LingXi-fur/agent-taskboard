## 背景

设计文档见 `docs/design/console.md`，必读。目标是做一个通用的、给所有人用的本地控制台。本单是第一阶段：只基于 atb 已有的任务数据（status、READY、CI、diffstat、历史），先把网页和 JSON API 做出来。Agent 会话观察是第二阶段（T030，由 OpenCode 做），本单要给它留好接口。

## 要做的事

1. **`atb serve [--port 8766] [--read-only] [--host 127.0.0.1]`**：只用标准库（`http.server`），前端是纯 JS 和 CSS，不需要构建步骤，不引用 CDN，离线可用。
   - 默认只监听 `127.0.0.1`。改成其他地址时必须显式加 `--host`，并打印警告。
   - 新增模块 `src/agent_taskboard/serve.py`，静态资源放在 `src/agent_taskboard/web/`，并确认 wheel 打包时会包含这个目录。
2. **JSON API v1：** `/api/v1/overview`、`/api/v1/tasks`、`/api/v1/tasks/{id}`、`/api/v1/events`，`/api/v1/sessions` 本单先返回空数组，留给 T030。
   - 数据复用 status、`review --json`、log 的现有逻辑，不要另写一套。
   - 用 SSE 推送更新（轮询 `.taskboard/` 和 git 状态，默认 5 秒，可配置）。
   - 在 `docs/api.md` 写清楚每个端点的字段。
3. **界面**（参考设计文档第 7 节）：
   - 顶部汇总条：活跃任务数、待审查数、今日合并数。
   - 按 agent 分泳道的今日时间线：用任务历史里的状态区间画条，颜色加图标加文字表示状态，不只靠颜色区分。
   - 任务详情：证据标签（范围、测试、CI、冲突、diffstat）、状态历史、验收清单。
   - 冷色调（青、蓝、灰蓝），提供亮色、暗色、高对比三套主题，跟随 `prefers-color-scheme`。
   - 键盘可以操作，1280px 和窄屏笔记本都能正常使用。
   - 中英文案放在 `web/locales/en.json` 和 `zh.json`，默认按浏览器语言选择。
4. **本单不做写操作按钮**（第四阶段再做）。唯一例外是"复制交接文本"，它只读取 `atb prompt` 的输出，在前端写入剪贴板。
5. **翻译设计文档：** 把 `docs/design/console.md` 翻译成 `docs/design/console.zh-CN.md`，两份内容保持一致。
